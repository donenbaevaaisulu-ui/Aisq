# Warehouse Management System

## Жоба туралы
Бұл жоба қоймадағы тауарларды есепке алуға арналған ақпараттық жүйе.

## Жобаның мақсаты
Қоймадағы тауарларды тіркеу, олардың санын бақылау, жеткізушілер туралы ақпаратты сақтау және тауарлардың кірісі мен шығысын есепке алу мүмкіндігін беру.

## Негізгі кестелер
1. **Category** — тауарлардың категориялары туралы ақпарат.
2. **Supplier** — жеткізушілер туралы ақпарат.
3. **Product** — қоймадағы тауарлар туралы мәліметтер.
4. **Transaction** — тауарлардың кірісі мен шығысы туралы ақпарат.

## Кестелер арасындағы байланыстар
- Category → Product (1:N)
- Supplier → Product (1:N)
- Product → Transaction (1:N)
